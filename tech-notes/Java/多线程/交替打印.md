# 交替打印

## Semaphore（信号量）实现

```java
public class AlternatePrint {
    private static Semaphore semA = new Semaphore(1); // A 先执行
    private static Semaphore semB = new Semaphore(0); // B 等待

    public static void main(String[] args) {
        new Thread(() -> {
            for (int i = 0; i < 5; i++) {
                try {
                    semA.acquire(); // 等待许可
                    System.out.println("A");
                    semB.release(); // 释放给B
                } catch (InterruptedException e) {}
            }
        }).start();

        new Thread(() -> {
            for (int i = 0; i < 5; i++) {
                try {
                    semB.acquire();
                    System.out.println("B");
                    semA.release();
                } catch (InterruptedException e) {}
            }
        }).start();
    }
}
```

**核心逻辑：**
```
semA 初始=1，semB 初始=0
A acquire semA（拿到）→ 打印A → release semB（给B）
B acquire semB（拿到）→ 打印B → release semA（给A）
→ 交替执行
```

acquire：获取许可，没有许可就阻塞等待
release：释放许可，唤醒等待的线程
