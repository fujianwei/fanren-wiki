# 引导式交互验收

日期：2026-11-07。

开局分为命格、天象、本心三步，由玩家点击继续；可回看或跳过介绍，选择本心页仍可展开全部背景信息与前世回响。入世前隐藏人生侧栏，减少同时出现的信息。

阶段安排分为选择重心、确认启程两步。选择后集中显示收益、代价与“推演这 N 年”主按钮，可以返回换选。年数继续读取原境界配置，只有确认推演才发送原有 ADVANCE_STAGE 操作；同步提交锁避免重复点击结算。

转场使用 150ms 渐出与 220ms 渐入，尊重减少动态效果设置。切换时焦点移到新步骤；小屏允许自然滚动，不固定高度裁掉长文。剧情、数值、事件和结局逻辑未修改。

验证通过：

- TypeScript、涉及文件 ESLint、生产构建、6 组 78 项现有测试。
- 320×568、390×844、844×390、1440×900 的浏览器交互验证，无横向溢出或运行异常。
- 完整执行命格→天象→返回→跳过→展开详情→选择本心→跳过命誓→选择重心→确认→返回换选→推演→事件→刷新。
- 介绍前后游戏状态一致；换选不改变年龄；同一次任务中连续点击推演两次，年龄只增加 5 年、阶段只增加 1，结算重心正确。
- 覆盖普通动画与减少动态效果两种设置；390px 手机视口确认主按钮位于底部导航上方。

以上为浏览器模拟检查，尚未进行真实手机验收。改动未自动发布。
