# 手机优先界面验收

日期：2026-11-06。基于 `45d01c7` 开发。

## 界面变化

- 手机使用底部常用功能栏：命途、行囊、灵市、历练、择道、图鉴。择道完成后保留其余五项。
- 状态栏直接显示境界、年岁、修为、灵石和天命。桌面保留顶部操作栏和人生侧栏。
- 手机场景使用完整 16:9 画面，标题和剧情在图片下方，避免长文遮住主角；宽屏保持场景叠字。
- 统一游戏字号、文字对比度和至少 44px 的操作目标；选项不依赖鼠标悬停才能识别。
- 出生、本心、命誓、生活重心、事件、冲关、濒死、结局、图鉴与首页适配小屏。
- 弹窗统一使用原生模态窗口，限制在动态可视高度内，支持长内容滚动、焦点循环、关闭后恢复焦点以及背景滚动锁定。
- 命途抽屉只保留一层内容滚动；已开始的一生可以从图鉴直接返回。
- 尊重屏幕安全区域、浏览器文字缩放和减少动态效果设置；减少手机环境粒子数量。
- 等待本地存档恢复后才挂载页面，修复刷新 `/game/play` 时误跳回出生页的问题。

玩法数据、美术文件、出生文案与蓝色火焰均保留。

## 验证结果

- TypeScript、ESLint、生产构建通过。
- 原有 6 组、78 项游戏测试通过。
- Chrome 独立浏览器上下文，生产服务：78 项布局和交互检查通过，未捕获运行异常。
- 尺寸：320×568、375×667、390×844、430×932、768×1024、1024×768、1440×900、844×390。
- 每种尺寸检查横向溢出、操作目标、储物袋、灵市、择道、档案三页、图鉴返回、弹窗焦点和 Escape 关闭。
- 实际走通开局、本心、命誓、选择生活重心、事件、选项结果、三轮战斗和择道。
- 补充检查冲关、濒死、结局、文字放大、模拟安全边距和改变可视高度。
- 截图前等待场景图片解码成功，人工复核手机事件页、最小屏布局、桌面布局、横屏弹窗和结局页。

浏览器检查使用模拟手机视口和触控环境；尚未在真实 iPhone / Android 设备上验收。

## 复查方式

```bash
npm ci
npx tsc --noEmit
npm run lint
npm test -- --runInBand
npm run build
npm start
```

用手机尺寸从 `/game` 开始一生，刷新 `/game/play` 确认继续原存档，再打开各个底部功能。以 320px 宽和横屏验证弹窗滚动，最后检查 `/game/atlas` 与 `/game/ending`。
