## 替换规则

1. 新图必须使用相同文件名，直接覆盖原文件。
2. 场景使用 2048×1152 PNG，图标使用 1024×1024 PNG。
3. 不使用当前占位图片作为风格参考图，避免继承粗色块风格。
4. 建议先生成 S01、S09、S13、S18 四张作为风格校准。
5. 每替换一张，在表格中把 `[ ]` 改为 `[x]`。
6. 全部替换后再运行一次构建和桌面/移动端验收。
