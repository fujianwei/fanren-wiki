# 炼气期事件场景提示词

> 文件路径：`/public/game/events/{eventId}.jpg`
> 境界特征：主角为少年/青年修士，道袍朴素，灵气浅薄，场景多为宗门山林、坊市街道。

## lq_001 — 山中偶遇受伤散修

```
中国传统水墨画风格，水彩与水墨混合插画，
宽幅横版构图（3:1比例），
前景：山路旁一名中年散修倚靠大树，衣衫破损，面色苍白，
胸口有墨色伤痕，眼神虚弱却带着警惕，
旁边站着年轻修士，表情犹豫，
背景：深山密林，晨雾弥漫，古树盘根，
远处山路蜿蜒消失在雾中，
色调：宣纸米白底色，灰绿色调，伤者部分红褐色点缀，
黑色墨迹晕染，整体氛围阴郁而压抑，充满抉择感，
无文字水印
```
