## lianqi — 炼气期

```
中国传统水墨画风格，水彩与水墨混合插画，
宽幅横版构图（3:1比例），
前景：一位十六七岁少年修士，半身像，面容清秀，眼神坚定中带着一丝迷茫，
身着宗门灰白色粗布道袍，腰间系布带，
背景：深山密林清晨，山间薄雾弥漫，远处松柏剪影虚化，
地面隐约可见淡青色灵气气流，若隐若现，
色调：宣纸米白底色，冷青色灵气光晕，黑色墨迹晕染，
边缘泼墨飞溅效果，整体氛围清冷空灵，充满未知与希望，
无文字水印，画面史诗感
```
