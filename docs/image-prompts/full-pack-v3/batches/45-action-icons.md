# 动作图标｜方形 UI 资产

> 本批共 10 张图。按顺序生成；先做本批事件主图，再将它作为同事件结果图的参考图。

## 统一风格

```text
专业级 16-bit / 32-bit JRPG 像素场景插画，仙侠游戏原画品质。由资深像素画师手工绘制：像素颗粒细密统一，清晰深色描边，每种材质 3 到 5 阶明暗，克制的 dithering，不用巨块像素，不做模糊放大。把中国水墨的山雾、宣纸质感、玉石、古木、青瓦、铜器、符箓和克制的旧金高光转译为精致像素画。横向 16:9，母版 2048×1152；关键人物在中央 4:3 安全区；底部 22% 为 UI 文字留出较暗低细节区。遇到选项结果图时，必须把对应场景主图作为直接参考，保持同一主角、同一服装、同一镜头和同一光源。
```
