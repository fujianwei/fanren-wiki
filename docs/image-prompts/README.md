# 游戏图片提示词总览

## 风格基调

参考样式：中国传统水墨画 + 水彩混合，宽幅横版构图（3:1比例），
前景人物精细写实、背景笔触写意虚化，宣纸米白底色，黑色墨迹晕染，边缘泼墨飞溅。

---

## 境界视觉规范（重要）

生成任何场景图时，主角的**外貌、气场、周身灵气、所处环境**必须符合当前境界的梯度设定。
越高阶，人物越超凡、环境越宏大险绝。

| 境界 | 人物外貌 | 气质 | 周身灵气 | 场景规模 | 环境特征 |
|------|---------|------|---------|---------|---------|
| 炼气期 | 少年 16-18岁，面容青涩 | 懵懂坚定，带怯意 | 微弱青色游丝，几乎不可见 | 宗门后山、小山坡 | 普通树林、膝盖高度薄雾 |
| 筑基期 | 青年 20余岁，面容沉稳 | 自信稳健，初入江湖 | 淡金色波动，轮廓隐约 | 高山山腰、灵脉区 | 站上云层、灵草遍野 |
| 结丹期 | 中年 30余岁，面容威严 | 气度自成，俯视众生 | 金色护体罡气一尺可见 | 高山绝顶、云海之上 | 脚踩云海、天雷为邻 |
| 元婴期 | 白发老者，寿元数百年 | 深不可测，超然绝尘 | 紫色元婴悬浮身外，神识如薄纱 | 高空虚空、星域边缘 | 人界如地图、法则铭文漂浮 |
| 化神期 | 白发苍苍，近乎神明 | 与天地同频，踏虚而立 | 金白神芒消融于虚空 | 天地交界、飞升光门前 | 灵界轮廓透出、天道铭文流动 |
