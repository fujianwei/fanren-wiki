# 像素游戏视觉参考与原创转化指南

> 版本：v3.2
> 适用对象：`full-pack-176` 中全部 176 张场景与图标
> 核心原则：**研究设计方法，不复制具体作品资产。**

## **一、为什么加入参考体系**

当前目标不是“把画面做成像素”，而是让它达到成熟商业像素游戏的可读性、层次和情绪表达：

- 玩家在 1 秒内知道角色在哪里。
- 390px 手机宽度下仍能分辨主体和关键道具。
- 画面有前、中、后景，而不是平涂背景。
- 人物有明确身份、服装、动作和剪影。
- 光照服务于叙事，而不是单纯堆粒子特效。
- 大量图片放一起时，像素密度、描边、色温和金色高光统一。

以下作品只作为高层设计参考。禁止复制其具体角色、服装、建筑、地图、构图、UI、徽记、字体、标识或可识别资产。

## **三、视觉融合比例**

不是把八款游戏拼在一起，而是按功能吸收：

| 设计任务 | 主要参考 | 转化结果 |
|---|---|---|
| 中国仙侠世界形态、服装、建筑 | 《逸剑风云决》《大侠立志传》 | 确定文化质感与人物身份 |
| 景深、逆光、电影化场景 | 《八方旅人 II》《星之海》 | 提升主次关系和画面呼吸感 |
| 生活细节、村镇与洞府 | 《风来之国》《星露谷物语》 | 增加真实生活痕迹与情绪温度 |
| 人物关系与暗色情绪 | 《莫塔之子》 | 强化因果、牵挂和牺牲 |
| 小道具、动作图标与交易 | 《夜勤人》《大侠立志传》 | 提高 48px 至 100px 尺寸下的识别 |

最终作品必须首先属于**凡人修仙模拟器自己的视觉世界**，而不是任何参考作品的仿制品。

## **四、每张场景图的执行标准**

### **1. 三层空间**

- 前景：枝叶、石柱、屋檐、雨线、香炉烟、人物肩部等局部遮挡。
- 中景：主角、关键人物、核心动作和关键道具。
- 远景：山门、群峰、洞府深处、坊市灯海、天门或战场规模。

三层不能全部同样清晰；远景降低对比度，前景用暗色剪影，中景最清晰。

### **2. 一个主光源**

每张图只能有一个明确的叙事主光源：

- 洞府：洞口天光或丹田灵光。
- 丹房：炉火。
- 墓穴：魂火或遗迹符文。
- 坊市：灯笼与店铺暖光。
- 渡劫：雷光。
- 天门：门后的金白神光。

其余光源只能作为辅助，不能抢主主体。

### **3. 人物剪影优先**

- 人物先能被认成“修仙者”，再谈细节。
- 必须有发髻或束发、交领、袖摆、腰带和至少一个身份道具。
- 手指、剑柄、药瓶、卷轴等关键动作部位不能糊成暗块。
- 不采用 Q 版大头比例。

### **4. 像素密度统一**

- 细节精细，但不能出现每个物件像素大小不一致。
- 人物脸部不追求写实五官，使用 2 到 4 个关键暗部与高光表达情绪。
- 金属、布料、石材、木材、水、烟和灵光必须有不同纹理。
- 不做“先画高清再粗暴马赛克”的假像素风。

### **5. 手机安全区**

- 关键人物与关键道具必须在中央 4:3 区域。
- 底部 22% 不放置必须看见的脸、手、证物或关键动作。
- 两侧 18% 只放可裁掉的枝叶、建筑延伸或环境云气。

## **五、同一场景复用时的连续性**

核心包不再为每个选项单独生成结果图。同一场景被多个事件复用时，必须保持：

- 同一主角、同一服装、同一发型。
- 同一地点、镜头方向、主光源和色温。
- 关键道具的位置关系可以变化，但不能消失后毫无解释。
- 通过动作、距离、天气、光线、破损和道具状态表现选择后果。
- 不使用大段文字解释，不让画面变成另一件无关的事。

## **六、统一原创约束**

所有提示词已经加入以下约束：

> Study only the high-level design principles of the referenced games. Do not copy or closely imitate any character, costume, building, emblem, environment, map, UI, composition, animation, logo, typeface, or recognizable asset. Create an original Chinese xianxia pixel-art visual identity for Fanren Wiki.

中文含义：

> 只学习参考作品的构图、层次、光效、生活细节和可读性；不得复制或高度近似任何角色、服装、建筑、徽记、场景、地图、UI、构图、动画、logo、字体或可辨识资产。必须为凡人修仙模拟器创造原创的中国仙侠像素视觉。

## **七、验收清单**

- [ ] 第一眼能看出地点与正在发生的事。
- [ ] 主角不是色块人，有明确服饰、发型和动作。
- [ ] 前景、中景、远景至少有三层差异。
- [ ] 只有一个明确的叙事主光源。
- [ ] 画面缩小到 390px 宽仍能识别主体。
- [ ] 底部文字覆盖后不遮挡关键证物和手部动作。
- [ ] 与参考作品没有可辨识的角色、建筑或构图复用。
- [ ] 与同包其他图片的像素密度、描边和金色高光一致。
