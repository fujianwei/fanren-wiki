# 化神期事件场景提示词

> 文件路径：`/public/game/events/{eventId}.jpg`
> 境界特征：主角已达化神，鹤发童颜或白发苍苍，神识覆盖方圆百里，周身天道法则铭文流动，站立处天地异象，场景触及飞升、大道、人界终结。

---

## hs_001 — 天道试炼

```
中国传统水墨画风格，水彩与水墨混合插画，
宽幅横版构图（3:1比例），
前景：主角直立于虚空之中，
周身天道金色法则铭文如链条般缠绕，
考验来自四面八方——火、雷、寒、毒四种天道之力同时轰压，
主角昂然不屈，神情庄严，
背景：天道试炼的虚无空间，
四方呈现不同元素的极致景观，无中生有，
色调：宣纸底色，金色天道铭文与四种元素色彩（红、金、蓝、绿）交织，
整体氛围磅礴宏大、天道至高考验，无文字水印
```
