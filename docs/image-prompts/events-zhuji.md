# 筑基期事件场景提示词

> 文件路径：`/public/game/events/{eventId}.jpg`

## zj_001 — 落难的结丹修士

```
中国传统水墨画风格，水彩与水墨混合插画，
宽幅横版构图（3:1比例），
前景：一名结丹期修士身着破碎的华贵道袍，
跌坐于地，胸口金丹气息紊乱外溢，面容疲惫而焦急，
周身有残缺的金色防护罩在消散，
背景：荒野，远处有战斗后留下的焦痕与碎石，
树木被灵力冲击折断，
色调：宣纸底色，残破金色光芒对比深黑墨色，
整体氛围狼狈危急，落差感强，无文字水印
```
