# 游戏图片生成提示词

## 基础风格模板

参考样式：中国传统水墨画 + 水彩混合，宽幅横版构图，前景人物精细、背景写意虚化，宣纸米白底色。

### 通用模板

```
中国传统水墨画风格，水彩与水墨混合插画，
宽幅横版构图（3:1比例），
前景：【人物描述】，半身像，面部细腻写实，
身着古代汉服/道袍，表情【情绪描述】，
背景：【场景描述】，大量雾气烟尘弥漫，
远景为【山林/城楼/古建筑】的深色剪影，虚化淡出，
色调：宣纸米白底色，黑色墨迹晕染，
暖橙黄色光源点缀，灰蓝色水墨渲染，
边缘有泼墨飞溅和墨水渗化效果，
背景笔触写意粗放，前景人物刻画精细，
整体氛围【神秘/紧张/空灵/苍茫】，
无文字水印，画面有史诗感
```
